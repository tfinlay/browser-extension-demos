# Browser Extensions Demos

A few example projects used to demonstrate features of browser extensions, these are used to accompany my talk on WebExtensions.

[View the presentation](./presentation.pdf)

## Getting started

The `native-messaging` project has slightly more complicated installation process, see the README there for details.

The other browser extensions can be installed via the standard unpacked/debug extension process in your browser. The `server` can be started with `go run`.
